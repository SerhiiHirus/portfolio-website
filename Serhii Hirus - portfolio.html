AI Strategy Co-pilot (Специализированный ИИ-агент)

Python · Claude API · AST Validation · VectorBT · Pandas / NumPy · FastAPI
Данный агент реализован в моем личном проекте hirus.systems ↗
Инженерная задача

Трансформация неструктурированных гипотез в строго верифицированные спецификации квант-стратегий. Базовые LLM галлюцинируют несуществующими методами и молча пропускают критические параметры риска (цену Stop-Loss, лимитные уровни входа, правила отмены ордеров).

Архитектура и реализация

Специализированный агент на Claude API (Anthropic) со строгой верификацией спецификаций. Проводит диалог по чеклисту пробелов, формирует понятную структурированную спецификацию и компилирует верифицированный код с AST-валидацией (контроль импортов, векторный расчет сигналов, защита от заглядывания в будущее).

Результат

100% покрытие обязательных параметров риска до запуска симуляции; устранение логических неоднозначностей на этапе диалога; сокращение времени от сырой идеи до готовой спецификации с часов до < 30 секунд.
