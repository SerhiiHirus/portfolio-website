Квантовая торговая лаборатория (hirus.systems )

Python · Vertex AI · VectorBT · Optuna · Neon PostgreSQL · React 19
Инженерная задача

Трансформация неструктурированных торговых гипотез с естественного языка в математически верифицированные алгоритмические стратегии с автоматическим out-of-sample бэктестингом и защитой от переобучения.

Архитектура и реализация

Тюнинг Vertex AI с Context Caching на 35.4k токенов под API VectorBT; статический анализ Python AST (ast.parse) для валидации синтаксиса до запуска; автоматический цикл самолечения (self-healing); асинхронный бэкенд на FastAPI с векторизованной симуляцией на VectorBT и байесовской оптимизацией в Optuna.

Результат

Генерация, верификация синтаксиса и бэктест квант-стратегии за < 3 секунд (ускорение в 4 раза благодаря context caching); 100% валидный исполняемый код через AST-фильтрацию; сквозной цикл от гипотезы до Walk-Forward анализа.
